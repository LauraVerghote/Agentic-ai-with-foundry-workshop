# Agentic AI with Microsoft Foundry Workshop

## 🎯 Workshop Overview

Welcome to this hands-on workshop where you'll learn to build an intelligent chatbot with Retrieval-Augmented Generation (RAG) capabilities using Microsoft Foundry. This workshop is portal-only — no local development environment needed.

### What You'll Build

By the end of this workshop, you will have a fully functional RAG chatbot that answers questions using your custom knowledge base, powered by Foundry IQ and Azure AI Search.

### Learning Objectives

- Understand the RAG (Retrieval-Augmented Generation) architecture
- Set up a knowledge base using Azure AI Search and Azure Blob Storage
- Learn to use Foundry IQ for knowledge base management with agentic retrieval
- Create an AI agent in Microsoft Foundry

## 📋 Prerequisites

### Required Knowledge
- Basic understanding of cloud services
- Understanding of basic AI/ML concepts

### Required Tools
- **Azure subscription**
- **Microsoft Foundry access**
- A modern web browser
